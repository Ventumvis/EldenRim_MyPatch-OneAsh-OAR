# EldenRim_MyPatch-OneAsh-OAR 2.3.12 EN

**Tested on:** Skyrim SE / AE **1.6.1179.0** (SkyrimSE.exe - 1.6.1179.0, 35.2 MB) - SKSE for 1.6.1179  
**Panel:** Spell Hotbar NG 1.9.3 by W1terr - https://www.nexusmods.com/skyrimspecialedition/mods/193653  
**Video Test:** https://youtu.be/Q0S9Y1gtm8s - Skyrim SE/AE 1.6.1179.0 - EldenRim MyPatch 2.3.12 EN Test on Spell Hotbar NG 4x10

Thanks to the author of EldenRim for allowing this patch.

## What this patch does
- 30 Ashes of War moved to clothing (OneAsh concept) - working on main ashes
- No potions - removed, not working on main ashes in EldenRim engine
- No spam notifications - Equip / Cast / Potion spam removed
- Fixed: WarAshResetList race condition (BOM marker, 0.35s delay, write-before-cast)
- Setup: 4 panels x10 slots for mouse + keyboard

## Requirements
- EldenRim mod
- Spell Hotbar NG 1.9.3 (SKSE, No ESP, No Papyrus, SKSE Menu Framework)
- Skyrim Special Edition / Anniversary Edition 1.6.1179.0
- SKSE64 for 1.6.1179, SkyUI, PapyrusUtil, Open Animation Replacer

## Installation (MO2 / Vortex)
1. Install EldenRim and its requirements
2. Install Spell Hotbar NG 1.9.3
3. Install this patch - let it overwrite EldenRim_MyPatch.esp
4. In game: SKSE Menu Framework -> Spell Hotbar NG -> Enable, Always Visible, bind Toggle key (H)
